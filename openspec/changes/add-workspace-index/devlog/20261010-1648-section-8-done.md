# Section 8 done: thread expansion and JSON notices

<!-- Section: 8 · Tasks: 8.1–8.2 · Base: a120ba3 -->

All in `src/query.zig`.

- **8.1 Thread expansion (D8).** `load` fills `Result.thread` for every devlog-note result. One prepared
  query on `files` (same member, change and archived flag, `note_time >` the result's), joined to
  `passages`, ordered by note time, path and ordinal. `Refs.of(path)` derives the stem, `HHMM` and
  (for `section-N-done` only) `N`. `Refs.foundIn(passage)` matches each passage. A thread entry is one
  later note with only its referring passages, joined by blank lines. Text output prints entries under
  the result as `↳ later note · <time> · <kind>` plus the path and an indented passage.
- **8.2** `Result.notices` is set from `Outcome.notices` on every result after `load`. `writeJson`
  serialises it, and main still prints the notices to stderr. The model-unavailable (both cases) and
  stale-index tests assert the field on every parsed `--json` line via `expectJsonNotices`.

## Decisions (Emmz's answers, 2026-10-10)

D8 and task 8.1 differed, so I asked first. Emmz took all three recommended options:
- **No bare `§N`.** D8 listed it, but the task and the spec don't, and it appears in almost every later
  note. D8 in `design.md` now says so.
- **Section references point only at `section-N-done` notes**, not at `section-N-start` ones. Passages
  carry the note's `# ` title, so otherwise a later "Section 1 done" note would thread under the
  start note through its own title. The wording of task 8.1 now says `section-N-done`.
- **A thread entry's text is the referring passage(s)**, not the whole later note.

Matching details, deliberately conservative:
- A filename or time token must stand alone. It can't be next to a letter, digit, `-` or `_`, so
  `…-policy-v2` and `10150` don't match.
- "note" can come before or after the time ("the 1015 note's", "note 1015"), across any whitespace,
  in any case. "notebook" and "notes" don't count.
- `section N done` is case-insensitive and allows any whitespace between the words. `§N-done` must be
  followed by a non-alphanumeric character.
