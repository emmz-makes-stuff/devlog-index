- **12.1 CLI integration tests** are in `src/cli_test.zig` (Emmz agreed the plan). They run the built
  binary in a temp copy of the fixture. The index is built through the library with the stub, so the
  binary sees another model and `query` degrades to lexical with a notice. HOME is set to an empty dir
  in the fixture and is the child's only environment variable.
  - `query --json`: exits 0; every stdout line parses as JSON; stderr has the `notice:` line naming
    `test://stub`.
  - `status`: exits 0. `eval` with no golden set: exits 1, naming `golden.json`. `status` outside any
    workspace: exits 1, naming `init`, with nothing on stdout.
  - Usage errors exit 2 with nothing on stdout. The cases are: `query` with no text, `query --k 0`,
    `query --jsno`, `update --json`, `status --bogus`, `init` with no arguments, and an unknown command.
  - **Build wiring:** the tests now get their own module (`mainModule()` in `build.zig`, called twice).
    That module carries `test_options.exe = exe.getEmittedBin()`, so `zig build test` compiles the exe
    first. The exe's own module can't carry this option, because the exe would then depend on itself.
    `fixture_workspace` moved to the test module too, which is fine because only tests read it.
  - **Gotcha:** the emitted-bin option is a path *relative to the build root*, e.g.
    `.zig-cache/o/<hash>/devlog-index`. The test resolves it against its own cwd (the build root)
    because the child runs with `cwd` set to the fixture. Without that, the spawn fails with a bare
    error trace.
- **12.2** Deleted `src/bench.zig` and its `bench-cold` branch. Its measurements are still in the §2
  and §7 notes.
- **12.3**
  - Every usage error, the unknown command included, now goes through `usageExit` (exit 2).
  - `query` rejects any unknown `--` argument instead of folding it into the text.
  - `update.Report.missing_members` is gone. The local `missing` list stays, because the
    deletion pass uses it to keep a missing member's files (`freshness.underMissingMember`). I first
    deleted it along with the field, and the build caught that. The update test is renamed "a missing

  - Every SQLite close is now `sqlite3_close_v2` (`db.zig` ×2 and the `sqlite.zig` test).
  - The `Embedder.embed` doc comment was already fixed in §11.
