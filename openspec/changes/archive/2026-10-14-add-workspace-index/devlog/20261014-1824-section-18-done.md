- **18.1** Change detection now lives once, in `freshness.zig` under "change detection, shared with
  `update`".
  - `Indexed` is a `files` row, now carrying `id`. `IndexedMap` and `loadIndexed` read the rows.
  - `missingMembers` lists the members missing right now.
  - `gone(path, row, missing)` says whether a path counts as removed: unseen, and not under a missing
    member.
  - `current(arena, io, path, old)` stats the file, then reads and hashes it unless its size and
    mtime match `old` with a 64-character hash. It returns null when the file vanished
    (`FileNotFound`/`NotDir`), and returns any other error raw.
  - `freshness.detect` and `update.takeSnapshot` both call `current` and catch the raw error into
    their own `readFailed` messages. `update`'s removed-files loop uses `gone`.
  - `update.Existing` is now an alias, `freshness.Indexed`, so its tests stay unchanged, as the task
    asks.
  - **One small behaviour change in freshness:** a row whose size and mtime match but whose hash is
    malformed is now read and hashed, so it counts as changed. Before, freshness trusted it. That
    matches what `update` does.
- **18.2** `passages_fts` is now `fts5(text, content = 'passages', content_rowid = 'id',
  tokenize = 'porter')`, and `schema_version` is `"2"`.
  - Inserts are unchanged.
  - `delete_fts` is now `INSERT INTO passages_fts(passages_fts, rowid, text) SELECT 'delete', id,
    text FROM passages WHERE id = ?`. It runs before the passage row is deleted, which was already
    the order in `deletePassage`.
  - `query.lexical` (`MATCH` + `bm25`) and the hand-built test index in `query.zig` work unchanged.
  - **Gotcha:** `SELECT count(*) FROM passages_fts` now reads through to `passages`. So the old
    assertion that this count equals the passage count is always true now; it doesn't check the
    index any more. The new test uses `integrity-check` instead.
  - New tests:

    - After rewriting the only note containing "thundering" and deleting another note,
      `integrity-check` passes, "zorbulon" matches once, and "thundering" no longer matches.
