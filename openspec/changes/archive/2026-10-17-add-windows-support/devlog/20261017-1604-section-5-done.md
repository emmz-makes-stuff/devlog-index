# Section 5 done: install.ps1 and README

<!-- Section: 5 · Tasks: 5.1–5.3 · Base: 1cacef9 -->

Emmz chose the local-HTTP-server test route (not a pre-release tag).

- `install.ps1`: parameters `-Version` (default latest, via the GitHub API `releases/latest`), `-InstallDir`
  (default `%LOCALAPPDATA%\Programs\devlog-index`) and `-BaseUrl` (default the GitHub releases download URL).
  The last two exist for testing; `-BaseUrl` requires `-Version`. Downloads the zip and `SHA256SUMS` to a temp
  dir, matches the archive's entry (handles `*name` binary-mode lines), compares with `Get-FileHash`, extracts,
  copies the exe, says whether the dir is on `PATH` and prints the command to add it. The temp dir is removed
  in `finally`. Errors go to stderr as `error: …` and exit 1; it is meant to be run as a file, not `irm | iex`.
- Tested under `pwsh` on macOS against the dry-run artifact of run 39042076641 (`dev-e396683` zip +
  `SHA256SUMS`, downloaded with `gh run download`) served from a loopback `python3 -m http.server`. The sandbox
  blocks loopback connections from `pwsh` ("Permission denied (127.0.0.1:8099)"), so these runs were unsandboxed.
  - OK: exit 0, installed exe SHA-256 `d9b7c626…` equals the zip member's.
  - Tampered (bytes appended to the zip): exit 1, "Checksum mismatch … expected: 74e01199… actual: 25a54437…
    Nothing was installed.", install dir not created, no temp dir left.
- README: Windows row in the target table, installer usage, `USERPROFILE` cache location (`HOME` first), symlink
  caveat. The "Windows isn't supported yet" sentence is gone.
- Gates: `GATES_EXIT:0` (`BUILD_EXIT:0`, `TEST_EXIT:0` with `120/125 tests passed (5 skipped)`, `SCRIPTS_EXIT:0`,
  `FORMAT_EXIT:0`, `VALIDATE_EXIT:0`).
