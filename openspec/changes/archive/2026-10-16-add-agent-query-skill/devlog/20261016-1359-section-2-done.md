**Gotchas found, now in the skill:**
- The sandbox cannot open nova's index: `devlog-index: cannot read …/.devlog-index/index.db; rebuild it with:
  devlog-index update --rebuild`. The index is fine; it opens unsandboxed. The cause is almost certainly that

  retry once with the sandbox lifted.

  says to group by `rel` before counting sources.
