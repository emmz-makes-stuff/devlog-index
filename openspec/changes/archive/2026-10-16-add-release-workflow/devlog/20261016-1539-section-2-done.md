# Section 2 done: packaging scripts

<!-- Section: 2 · Tasks: 2.1–2.2 · Base: 36759bb -->

Added, all under `scripts/`:
- `package-release.sh <version> <target> [prefix]` → `$OUT_DIR/devlog-index-<version>-<target>.tar.gz`
  (`OUT_DIR` defaults to `dist/`), holding `devlog-index` (0755) and `LICENSE` (0644) at the top level.
  Reads `<prefix>/bin/devlog-index`, prefix defaulting to `zig-out`. Prints the archive path.
- `checksums.sh <dir>` → `SHA256SUMS` with bare file names, via `sha256sum` or `shasum -a 256`.
- `test-release-scripts.sh`: fake-binary tests of both. Wired as `make test-scripts` and **added to
  `make gates`** (a small scope addition, so the scripts are checked on every gate run).
- `dist/` added to `.gitignore`.

**Decisions.**
- Target names are `macos-arm64`, `linux-x64`, `linux-arm64` (the spec's `<target>`), not Zig triples. The
  workflow in §4 maps them: `aarch64-macos`, `x86_64-linux`, `aarch64-linux`. The script rejects anything else,
  including `windows-*`.
- The script only packages; it doesn't build. §4 builds each target with `--prefix out/<name>` and passes
  that as `[prefix]`.
- Ownership is normalised to root (`--uid 0 --gid 0 --uname root --gname root` on bsdtar,
  `--owner=0 --group=0 --numeric-owner` on GNU tar). Found in self-review: the first real archive recorded
  `rendle staff`, which a release must not carry. Covered by a test.

**Verification.**
- Real build: `make release` → `RELEASE_EXIT:0`, `Mach-O 64-bit executable arm64`. Packaged as
  `v0.0.0-local`: `-rwxr-xr-x root/root 6338688 devlog-index`, `-rw-r--r-- root/root 1061 LICENSE`.
  `shasum -a 256 -c SHA256SUMS` → `OK`; the extracted binary runs (`Usage: devlog-index <command> ...`).
- GNU tar: `bash scripts/test-release-scripts.sh` in the OrbStack `ubuntu` machine (tar 1.35) → `0 failure(s)`.
- A test bug first failed three checks: `sort` ordered `LICENSE`/`devlog-index` by locale. Fixed with
  `LC_ALL=C`; the packager was fine.

**Self-review** (`git diff 36759bb`): archive name, contents, modes, ownership and checksums are covered by
the spec's requirements and by tests; no dead code; `dist/` ignored. Nothing else found.

Gates: `BUILD_EXIT:0`, `TEST_EXIT:0`, `SCRIPTS_EXIT:0`, `FORMAT_EXIT:0`, `VALIDATE_EXIT:0`, `GATES_EXIT:0`
(119/124 tests passed, 5 skipped).
